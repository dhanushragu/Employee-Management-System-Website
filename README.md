# PeopleDesk — Employee Management Frontend

A responsive employee management dashboard built with **HTML, CSS and JavaScript**.

## Features
- Dashboard cards for total, active and on-leave employees
- Employee directory with search and department/status filters
- Add and edit employee forms
- Delete employee records with confirmation
- Department overview cards and team distribution bars
- Responsive sidebar and mobile layout
- Browser `localStorage` persistence for frontend demo records

## Run the project
1. Download and extract the ZIP file.
2. Open `index.html` in your browser.
3. No installation or server is required.

## Project files
- `index.html` — page structure
- `style.css` — layout and styling
- `script.js` — demo data and frontend interactions

## Important
This version is frontend-only. Data is stored in the current browser using `localStorage`; it is not stored in MySQL and will not sync between devices. In the next phase, a Python Flask backend and MySQL database can be connected.
